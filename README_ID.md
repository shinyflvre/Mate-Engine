## Tentang Proyek

**Mate Engine** dibuat sebagai alternatif gratis untuk **Desktop Mate**.

Kenapa? Karena **Desktop Mate** mematok harga sebesar **$10-$25 USD** untuk satu model karakter - harga yang setara dengan game lengkap di Steam. Selain itu, modifikasi dan penggunaan model kustom telah dinonaktifkan di versi terbaru.

**Mate Engine** memecahkan kedua masalah tersebut:

- Ini **sepenuhnya gratis**
- Ini mendukung **kustomisasi avatar VRM**
- Ini **sumber terbuka dan dapat dimodifikasi**

## Performa

![Mate Engine Preview](https://i.imgur.com/MTbnIeE.png)

**Mate Engine** itu ringan dan efisien. Penggunaan RAM tergantung pada ukuran tekstur avatar. Sebagai contoh, model "Alice" berkualitas tinggi menggunakan \~190MB untuk memori tekstur, mengakibatkan total penggunaan RAM sebesar \~200MB. Menggunakan model yang lebih ringan akan mengurangi ini secara lanjut.

## Fitur Utama

- **Animasi Diam** - Berulang saat beristirahat di desktop Anda
- **Animasi Seret** - Mengambang saat digerakkan
- **Animasi Menari** (Eksperimental) - Bereaksi terhadap musik dari Spotify, Firefox, etc.
- **Pemuat VRM** - Mendukung semua model `.VRM` yang valid
- **Area Sentuhan** - Mendukung interaksi pada wajah/kepala
- **Mod Kustom** - Tambahkan efek, suara, dan lainnya dengan mudah
- **Menu Opsi** - Klik kanan atau tekan `M` untuk membuka pengaturan
- **Toggle Selalu di Atas, Kontrol FPS, Mode Chibi**, dan lainnya

## Fitur Mendatang (Pra-Rilis 5-10)

- **Duduk di Jendela & Taskbar** – Dapat duduk di bilah judul aplikasi desktop apapun
- **Kustomisasi Warna Menu** – Sesuaikan tampilan UI dengan tema pilihan Anda

## Cara Menggunakan

1. Buka bagian **Releases** (di panel sebelah kanan), atau klik [link ini](https://github.com/shinyflvre/Mate-Engine/releases).
2. Unduh file ZIP yang ditandai sebagai *release public* (bukan *source code*).
3. Ekstrak dan jalankan `MateEngineX.exe`.
4. Klik kanan pada avatar atau tekan `M` untuk membuka menu pengaturan.

## Pertanyaan yang Sering Diajukan

**Q: VRM saya tidak dapat dimuat atau di-inject!**  
A: Ini biasanya berarti file `.VRM` Anda diekspor secara tidak benar. Masalah umum termasuk struktur armature yang rusak atau shader yang tidak didukung. Gunakan exporter resmi dan uji kompatibilitasnya.

**Q: Apakah Hatsune Miku sudah termasuk?**  
A: Tidak. Silakan unduh secara terpisah dari [halaman Booth ini](https://booth.pm/en/items/3226395).

**Butuh bantuan konversi?**  
Lihat panduan resmi ini: [Panduan Konversi VRM](https://vrm.dev/en/vrm/how_to_make_vrm/)  
(*Catatan: Saya tidak dapat memberikan dukungan untuk proses konversi model.*)

## Panduan Pengembang (Developer)

Ingin berkontribusi? Penyiapannya mudah:

1. Clone atau unduh repositori ini dan ekstrak folder-nya.
2. Buka **Unity Hub** → **Add Project From Disk**
3. Pilih folder `Mate-Engine-BRANCH`
4. Muat proyeknya, lalu buka scene berikut:
   `Scenes - USED FOR MATE ENGINE > Mate Engine Main`

> ⚠️ Hindari scene seperti *Mate Engine InDev* kecuali Anda berada di cabang pengembangan (dev branch).

## Peringatan Antivirus
